# 論文整形

## 概要
論文に含まれている図表の番号付け及び書式チェック、図表リストの作成、参考文献の書式チェックとリスト化、その他論文の書き方2021の構成などの原則に違反していないかのチェックと修正を行います。

## 実行手順

### 1. 図表の番号付けと書式チェック

#### 図のチェック項目
- [ ] すべての図に `{#fig:識別子}` 形式のIDが付与されているか
- [ ] 図の題名が画像のaltテキスト（`![題名]`）に記述されているか
- [ ] 図の題名は図の下に配置されているか（表とは逆）
- [ ] 本文中で `図[@fig:識別子]` 形式で参照されているか
- [ ] 図の番号が連番になっているか（欠番がないか）
- [ ] 図の参照が本文中に存在するか（未参照の図がないか）

#### 表のチェック項目
- [ ] すべての表に `{#tbl:識別子}` 形式のIDが付与されているか
- [ ] 表の題名が表の直後に `: 表の題名 {#tbl:識別子}` 形式で記述されているか
- [ ] 表の題名は表の上に配置されているか（図とは逆）
- [ ] 本文中で `表[@tbl:識別子]` 形式で参照されているか
- [ ] 表の番号が連番になっているか（欠番がないか）
- [ ] 表の参照が本文中に存在するか（未参照の表がないか）

### 2. 図表リストの作成

#### 00_ListFigures.md の作成
- [ ] `Auto_Pandoc_KIC/chapters/` ディレクトリ内の全章ファイルから図を抽出
- [ ] 図の番号、題名、出現章をリスト化
- [ ] 以下の形式で `00_ListFigures.md` を作成：

```markdown
# 図目次

1. 図1: [題名] (第X章)
2. 図2: [題名] (第Y章)
...
```

#### 00_ListTables.md の作成
- [ ] `Auto_Pandoc_KIC/chapters/` ディレクトリ内の全章ファイルから表を抽出
- [ ] 表の番号、題名、出現章をリスト化
- [ ] 以下の形式で `00_ListTables.md` を作成：

```markdown
# 表目次

1. 表1: [題名] (第X章)
2. 表2: [題名] (第Y章)
...
```

### 3. 参考文献の書式チェックとリスト化

#### 参考文献のチェック項目
- [ ] 本文中で引用されているすべての参考文献が `references.bib` に存在するか
- [ ] `references.bib` に存在するが本文中で引用されていない文献がないか（不要な文献の削除）
- [ ] 参考文献の書式が IPSJ Journal の「参考文献の記述形式（2.8.4）」に準拠しているか
  - 和文には全角コンマ「，」、全角コロン「：」、全角ピリオド「．」を使用
  - 英文には半角コンマ「,」、半角コロン「:」、半角ピリオド「.」を使用
  - 半角コンマの直後には半角スペースを入れる
  - 巻には「Vol.」、号には「No.」、ページには「pp.」を付ける
  - 和文雑誌: `[n] 著者名：標題，雑誌名，Vol. 巻，No. 号，pp. 始-終（年）．`
  - 英文雑誌: `[n] 著者名: 標題，雑誌名（イタリック），Vol. 巻，No. 号，pp. 始-終（年）.`
  - 国際会議: `[n] 著者: 論文名, Proc. プロシーディング名（イタリック）, pp. 始-終, 版元（年）.`
  - Webサイト: `[n] 著者名：Webページの題名，Webサイトの名称，入手先（媒体表示），入手先〈URL〉（参照日付）．`

#### 12_references_heading.md への反映
- [ ] 本文中で引用されている参考文献を抽出
- [ ] 引用順に番号を付与（[1], [2], [3], ...）
- [ ] IPSJ Journal の書式に従って整形
- [ ] `12_references_heading.md` の「（ここに参考文献リストが自動生成されます）」部分を置き換え

### 4. 論文構成のチェック

#### 章構成のチェック
- [ ] 以下の章が適切な順序で存在するか：
  - `00_title.md`: 標題
  - `01_abstract.md`: 和文アブストラクト（600字以内）
  - `02_introduction.md`: 序論
  - `03_related_work.md`: 関連研究
  - `04_analysis.md`: 課題の分析
  - `05_proposal.md`: 解決策の提案
  - `06_system_spec.md`: システム仕様
  - `07_implementation.md`: 実装
  - `08_evaluation.md`: 評価
  - `09_discussion.md`: 考察
  - `10_conclusion.md`: 結論
  - `11_acknowledgements.md`: 謝辞
  - `12_references_heading.md`: 参考文献
  - `13_appendix.md`: 付録（任意）

#### 書式の統一チェック
- [ ] 句読点が統一されているか（全角「．」「，」または全角「。」「、」のどちらかに統一）
- [ ] 用語の表記が統一されているか（例：「コンピューター」「コンピュータ」の統一）
- [ ] 章番号の自動付与が正しく機能しているか
- [ ] 見出しの階層が適切か（# が章、## が節、### が項、#### が目）

#### その他のチェック項目
- [ ] アブストラクトが字数制限内か（和文600字以内、英文200語以内）
- [ ] 図表が本文中で必ず参照されているか
- [ ] 参考文献が本文中で必ず引用されているか
- [ ] 画像ファイルのパスが正しいか（存在するか）

## 実行時の注意事項

1. **バックアップ**: 修正を行う前に、現在のファイルをバックアップすることを推奨します
2. **段階的実行**: 各チェック項目を段階的に実行し、問題があれば即座に報告します
3. **修正の確認**: 自動修正を行った場合は、修正内容を明示し、ユーザーの確認を求めます
4. **参考資料**: 以下の資料を参照しながらチェックを行います：
   - `docs/KIC/IW/論文の書き方2021(最初に読んでください).pdf`
   - `docs/KIC/IW/論文誌ジャーナル（IPSJ Journal）原稿執筆案内.md`
   - `.cursor/rules/ipsj_bibliography.mdc`

## 出力ファイル

- `Auto_Pandoc_KIC/chapters/00_ListFigures.md`: 図目次
- `Auto_Pandoc_KIC/chapters/00_ListTables.md`: 表目次
- `Auto_Pandoc_KIC/chapters/12_references_heading.md`: 参考文献リスト（更新）

## チェックレポート

実行後、以下の内容を含むチェックレポートを生成します：

1. **図表チェック結果**
   - 検出された図の数と一覧
   - 検出された表の数と一覧
   - 問題点と修正内容

2. **参考文献チェック結果**
   - 本文中で引用されている参考文献の数
   - 書式の問題点と修正内容
   - 未引用の参考文献（削除推奨）

3. **構成チェック結果**
   - 章構成の問題点
   - 書式の統一性の問題点
   - その他の推奨事項
